# فيديو الستوري بورد (animatic)

- `ohod-film-animatic.mp4`: الفيلم السينمائي، ٣:٤٠ تقريباً، ١٢٨٠×٧٢٠.
- `ohod-sales-animatic.mp4`: النسخة البيعية، ١:٣٠، ٥٤٠×٩٦٠ (طولية للواتساب).

**هذي مسودة توقيت، مو الفيلم النهائي.** فيها: الصور من النظام الحقيقي (ببيانات تجريبية) والنص على الشاشة بالتوقيت المكتوب في الصفحة.
ما فيها: تعليق صوتي، موسيقى، مؤثرات، تصوير حقيقي للمحل، ولا حركة كاميرا.

تسجيلها من الصفحة نفسها:
```
python3 -m http.server 8788 --directory .
node film/tools/record-animatic.cjs film  <مجلد>
node film/tools/record-animatic.cjs sales <مجلد>
```
