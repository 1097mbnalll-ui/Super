# مطابقة الموقع والتطبيق (شرط إجباري من المالك، ١٢ نوفمبر ٢٠٢٦)

أي ميزة للزبون في `index.html` لازم تكون في التطبيق الأصلي (`mobile/ios-native`) بنفس السلوك ونفس حقول الخادم.
لما تضيف ميزة للموقع: أضفها هنا وفي التطبيق. ✅ = موجودة، 🟡 = جزئية، ⛔ = ناقصة.

## الطلب والسلة والعروض
| الميزة | الحالة |
|---|---|
| تصفح، أقسام، أقسام فرعية، «قريباً» | ✅ (ناقص: عدد كل فرعي، إخفاء الفرعي الفاضي، شريحة «أخرى») |
| خصم `old` وعرض الكمية `autoOffer` وخيارات البيع `packs` | ✅ |
| كل منتج بـ ٠٫٩٥ `deal95` (مفاتيح `d:<id>`، يفتح فوق `min`) | ⛔ |
| عرض اليوم `daily` (مفاتيح `t:<id>`، يتغير يومياً، عداد) | ⛔ |
| الباقات (بنر `style:bundle` + `bprice`، مفاتيح `x:<ban>:<pid>`) | ⛔ |
| `forYou` / `forOnly` (مختارات المالك) | ⛔ |
| `sugg` «يحلى معه»، `badge` المنتج، «باقي N بس» `lowAt`، «الحد N لكل طلب» | ⛔ |
| الحد لكل طلب يجمع الحبة والكرتون لنفس المنتج | 🟡 |
| البنرات: `img`/`showText`، `color2`، `dark`، هدف `b:<id>` و`deals`، تدوير تلقائي | 🟡 |
| ترتيب الرئيسية `layout`، كرت التوصيل المجاني | 🟡 |
| البحث: الأخيرة، مقترحات، `name_en`، اسم القسم، باركود جزئي، استبعاد `print` | 🟡 |
| ملاحظات الطلب `note` | ⛔ |
| بدّله/شيله/اتصل: الافتراضي في الموقع `call` | 🟡 |
| `maxKm` + `shop` + `mapCenter` (بدون منطقة مرسومة) و`too_far` بالمسافة | ⛔ |
| خدمة الطباعة | ⛔ |
| الطلب بالواتساب لما يتعذر الإرسال | ⛔ |

## بعد الطلب
| الميزة | الحالة |
|---|---|
| التتبع والخريطة وETA وعدد التوصيلات قبلك | ✅ (ناقص: المسافة `m` وحداثة الموقع `at`) |
| البديل بموافقة الزبون `/sub-answer` | ✅ |
| الإلغاء `/cancel` | 🟡 (ناقص: أسباب الإلغاء، احترام `track`) |

| المحفظة والكاش باك (`/wallet/*`، `walletAmount`، `walletToken`) | ⛔ |
