# مطابقة الموقع والتطبيق (شرط إجباري من المالك، ١٢ نوفمبر ٢٠٢٦)

أي ميزة للزبون في `index.html` لازم تكون في التطبيق الأصلي (`mobile/ios-native`) بنفس السلوك ونفس حقول الخادم.
لما تضيف ميزة للموقع: أضفها هنا وفي التطبيق.
**قرار المالك (١٢ نوفمبر ٢٠٢٦): وقف أي عمل على النسخة الإنجليزية في التطبيق ولا تحدّثها.** الإنجليزي مستثنى من شرط المطابقة. ✅ = موجودة، 🟡 = جزئية، ⛔ = ناقصة.

## الطلب والسلة والعروض
| الميزة | الحالة |
|---|---|
| تصفح، أقسام، أقسام فرعية (بالعدد و«أخرى»)، «قريباً» | ✅ |
| خصم `old` وعرض الكمية `autoOffer` وخيارات البيع `packs` | ✅ |
| كل منتج بـ ٠٫٩٥ `deal95` (مفاتيح `d:<id>`، يفتح فوق `min`) | ✅ |
| عرض اليوم `daily` (مفاتيح `t:<id>`، يتغير يومياً، عداد) | ✅ |
| الباقات (بنر `style:bundle` + `bprice`، مفاتيح `x:<ban>:<pid>`) | ✅ |
| `forYou` / `forOnly` (مختارات المالك) | ✅ |
| `sugg` «يحلى معه»، `badge` المنتج، «باقي N بس» `lowAt`، «الحد N لكل طلب» | ✅ |
| الحد لكل طلب يجمع الحبة والكرتون لنفس المنتج | ✅ |
| البنرات: `img`/`showText`، `color2`، `dark`، هدف `b:<id>` و`deals`، تدوير تلقائي | ✅ (ناقص: بنر «عرض كمية» يفتح المنتج بدون ما يختار الخيار) |
| ترتيب الرئيسية `layout`، كرت التوصيل المجاني، نص البحث المتبدل | ✅ |
| البحث: الأخيرة، مقترحات، `name_en`، اسم القسم، باركود جزئي، استبعاد `print` | ✅ |
| ملاحظات الطلب `note` | ✅ |
| بدّله/شيله/اتصل: الافتراضي `call` | ✅ |
| `maxKm` + `shop` + `mapCenter` و`too_far` بالمسافة | ✅ |
| خدمة الطباعة (حاسبة، أقل طلب، ملاحظة الطلب، إرسال الملف بالواتساب) | ✅ |
| الطلب بالواتساب لما يتعذر الإرسال | ✅ |
| قسم «الكراتين والشدّات» (`cartons`: الوحدة كرتون/شدّة أو خيار كرتون) والبحث بالوحدة | ✅ |
| التوصيل المجاني «كان X وصار مجاني» (`store.feeWas`) وينحسب ضمن «وفّرت» | ✅ |
