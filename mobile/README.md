# تطبيق متاجر أحد للزبائن (آيفون وأندرويد)

غلاف **Capacitor** حول صفحة المتجر نفسها (`index.html`). نفس الكود لآبل وقوقل والموقع، فما نصون نسخة ثانية.
تطبيق المندوب (`android-driver/`) منفصل ولا يمرّ من هنا.

## كيف يشتغل
- `npm run www` يبني `www/` من `../index.html` ويحقن علامة `window.__NATIVE_STORE__` (الصفحة تقرأها).
- داخل التطبيق: تختفي الإدارة والمندوب والمجهز (ما فيها دخول ولا روابط `#driver`)، وتخفي واجهة إشعارات الويب (لين تجي الإشعارات الأصلية).
- صور المنتجات (`p/…`) والبيانات (`data.json`) تنزل من الموقع، فالأسعار والمنتجات والصور تتحدث **بدون تحديث من المتجر**. صور الأقسام (`cat/`) داخل التطبيق.
- تغيير **كود** الصفحة يحتاج إصدار جديد للمتجر (أو تحديث مباشر OTA لاحقاً).

## الأوامر
```
cd mobile
npm install
npm run sync        # يبني www ويزامنه مع ios/ و android/
```
بناء آيفون يحتاج Xcode 26 (ماك أو خدمة بناء سحابية مثل Codemagic). بناء أندرويد يحتاج Android SDK (أو خدمة سحابية).
الأيقونات والشاشة الافتتاحية من `assets/`: `npx capacitor-assets generate --ios --android`.

## معلومات التطبيق
| | |
|---|---|
| الاسم | متاجر أحد |
| المعرّف (Bundle / Application ID) | `sa.ohod.store` (**ما ينغيّر بعد النشر**) |
| أندرويد | الحد الأدنى 24 والهدف 36 (قالب Capacitor 8) |
| آيفون | iOS 15 وما فوق، عمودي بس |
| الصلاحيات | الموقع (لتحديد مكان التوصيل) |

## لازم يتغير في الخادم (Cloudflare)
الخادم يرفض أي طلب من مصدر ما هو بالقائمة. أضف مصدرين للمتغير `ALLOWED_ORIGIN` (مفصولة بفاصلة، والأول يبقى موقع المتجر):
```
https://1097mbnalll-ui.github.io,capacitor://localhost,https://localhost
```
- `capacitor://localhost` = آيفون، `https://localhost` = أندرويد.
- بعد شراء الدومين أضفه لنفس القائمة (وأبقِ القديم).

## اللي سويناه (المرحلة ١) وما جُرّب
- ✅ بناء `www` وفحصه في المتصفح: الأقسام الخاصة مخفية، الصور والبيانات تنزل من الموقع، سياسة الخصوصية تفتح.
- ✅ مشروعا iOS و Android انولّدا، الأيقونات والشاشة الافتتاحية، وصف الصلاحيات بالعربي، بدون أي بيانات سرية.
- ⏳ **ما انجرّب على جهاز حقيقي ولا انبنى على ماك/Android SDK** (البيئة هنا ما تدعم). أول بناء حقيقي يطلع نواقصه.

## المرحلة ٢ (قبل التقديم لآبل، لأن قاعدة 4.2 ترفض «موقع داخل غلاف»)
إشعارات أصلية (APNs/FCM) من الخادم، وتحديد الموقع الأصلي، وفتح الخرائط والاتصال والواتساب بتطبيقاتها، وتجربة الشاشات ذات الحافة (Safe Area).
الخادم يحتاج: مفتاح APNs (.p8) وحساب خدمة FCM كأسرار Cloudflare (**تدخلها بنفسك، ولا تُرسل في المحادثة**).

## قائمة التقديم (App Store Connect / Play Console)
- رابط سياسة الخصوصية: `…/privacy.html` (موجودة، وراجعها قبل التقديم).
- حساب تجريبي للمراجع + طلبات تجريبية + الخادم شغّال طول المراجعة.
- لقطات شاشة، ووصف، وكلمات بحث بالعربي.
- نموذج خصوصية آبل (App Privacy) ونموذج «أمان البيانات» في قوقل: نجمع الاسم والجوال والعنوان والموقع (تحديد مكان التوصيل).
- ما فيه دفع داخل التطبيق (كاش وشبكة عند الاستلام): سلع حقيقية، فما نحتاج IAP.
- لو أضفنا إنشاء حساب ذاتي: لازم زر «حذف الحساب» داخل التطبيق.
