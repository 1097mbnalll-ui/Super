# متاجر أحد

موقع سوبر ماركت ومخبز **متاجر أحد** في حي الرمال: قائمة المنتجات بالأقسام والعروض، بحث، وسلة ترسل الطلب على واتساب للتوصيل لين باب البيت.

الموقع: https://1097mbnalll-ui.github.io/Super/

## تعديل المنتجات

كل المنتجات والأسعار وبيانات المحل موجودة داخل `index.html` في الوسم `<script id="store-data">` بصيغة JSON.
